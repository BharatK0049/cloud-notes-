# Cloud Computing — Basics

## Definition
Cloud computing is the on-demand delivery of computing resources over the internet with pay-as-you-go pricing.

## Why cloud exists
- No upfront hardware cost
- No data center management
- Easy scaling
- Faster development

## Core cloud resources
- Compute → EC2 (virtual servers)
- Storage → S3 (file/object storage)
- Networking → VPC (connectivity)

## Key advantages
- On-demand provisioning
- Global access over internet
- Pay only for what you use

# Cloud Deployment Types

Cloud resources can be deployed in three main ways depending on business needs, control requirements, and regulations.

---

## 1. Cloud Deployment
All infrastructure and applications run in the cloud.

### What it means
- Resources are hosted entirely on a cloud provider (AWS, Azure, GCP)
- No on-premise hardware

### When it’s used
- New applications
- Startups and modern web apps
- Scalable ML / data workloads

### Key benefits
- High scalability
- Pay-as-you-go
- No infrastructure maintenance

---

## 2. On-Premises Deployment
Infrastructure is hosted and managed locally by the organization.

### What it means
- Servers and storage are owned and maintained by the company
- May use virtualization tools, but not cloud services

### When it’s used
- Strict security or regulatory requirements
- Low-latency systems
- Legacy applications

### Limitations
- High upfront cost
- Limited scalability
- Full maintenance responsibility

---

## 3. Hybrid Deployment
Combination of cloud and on-premises infrastructure.

### What it means
- Some resources run on-premises
- Some resources run in the cloud
- Both environments communicate with each other

### When it’s used
- Gradual cloud migration
- Compliance-driven workloads
- Cloud analytics on on-prem data

### Example
- Legacy app on-prem
- Data processing and analytics in the cloud

---

## Note
Multi-cloud (using multiple cloud providers) is often considered a form of hybrid deployment.
