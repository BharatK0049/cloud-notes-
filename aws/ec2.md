## What is Amazon EC2?
**:contentReference[oaicite:0]{index=0} (EC2)** is AWS’s core **compute service** that provides resizable virtual servers, known as **instances**, to run applications in the cloud.

## Why Compute Matters
Most businesses follow the **client–server model**:
- Client sends a request
- Server processes it
- Server sends a response

Whether it’s healthcare, manufacturing, insurance, or video streaming, applications need **raw compute power** to function. EC2 provides that compute on demand.

## EC2 vs On-Premises Servers
**On-premises:**
- High upfront cost
- Long setup time
- Fixed capacity
- Hardware maintenance

**EC2:**
- No upfront hardware investment
- Launch servers in minutes
- Scale capacity up or down
- Pay only for what you use

## Key Characteristics of EC2

### On-Demand Provisioning
- AWS maintains massive compute capacity
- You request instances when needed
- Instances launch and boot within minutes
- Stop or terminate anytime — no lock-in

## Software Control
You have full control over what runs on the instance:
- Custom business applications
- Web applications
- Databases
- Third-party enterprise software

AWS provides the infrastructure — **you control the workload**.

## Scaling EC2 Instances

### Vertical Scaling
- Increase or decrease:
  - CPU
  - Memory
- Resize an instance as application demand changes
- Useful when a single server needs more power

## Networking Control
- You control:
  - Which requests reach your instance
  - Public vs private access
- Networking rules determine security and accessibility
- Detailed networking concepts are covered later

## Compute as a Service
- Virtual machines are not new
- AWS made them:
  - Faster to acquire
  - Easier to manage
  - More cost effective
- EC2 is **Compute as a Service**, not hardware ownership

## Key Takeaways
- EC2 provides flexible, on-demand compute
- Instances are virtual machines managed by AWS
- You control OS, software, scaling, and access
- AWS handles the heavy infrastructure lifting

## Bottom Line
Amazon EC2 lets you focus on **building and running applications**, while AWS takes care of the servers behind the scenes.
